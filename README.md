# Набор скиллов для работы с картами Социотеха
Социотех позволяет работает со всеми функциями через ИИ-агента, подключенного к MCP-серверу. Инструкция для подключения: https://sociotech.center/mcp

Для того, чтобы ИИ-агент не отклонялся от стандартов Связанного SWOT-анализа, Карты гипотез, Карты процесса-опыта и Карты реализации историй, ему нужно дать правильные навыки, в рамках которых она точно не ошибется.

В этом проекте собраны скиллы для ИИ под каждый инструмент Социотеха.
